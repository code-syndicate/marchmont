# Design reference

`ferrous-and-oak/` is the static export used as the visual starting point for
Marchmont. It is reference only and none of it ships.

What carries over: token values (warm neutral ground, hue 18 accent, zero
radius), the Fraunces / Bitter / Inter pairing, spacing rhythm, listing and
detail page density, gallery treatment.

What does not: the compiled Tailwind stylesheet, the Ferrous & Oak brand, the
Providence Rhode Island single-market framing, and the light default ground.
Marchmont is darker, serif-led and oxblood-accented. See section 2 of the spec.
